WORKBENCH PROCESS
-------------------------

1. Open PassMark Volatility Workbench
2. File -> Open Memory Image
3. Select memory.raw / memory.dmp / memory.mem
4. Run plugins in this order:

windows.info
windows.pslist
windows.psscan
windows.pstree
windows.cmdline
windows.filescan
windows.handles
windows.envars
windows.netscan
windows.malfind
windows.cmdscan
windows.consoles
windows.registry.hivelist
windows.dlllist
windows.svcscan
windows.driverscan

------------------------------------
MOST IMPORTANT PLUGINS
------------------------------------

windows.info        -> OS Information
windows.pslist      -> Running Processes
windows.psscan      -> Hidden/Terminated Processes
windows.pstree      -> Parent Child Process
windows.cmdline     -> Executed Command Line
windows.filescan    -> Open/Deleted Files
windows.handles     -> Open Handles
windows.envars      -> Environment Variables
windows.netscan     -> Network Connections
windows.malfind     -> Malware Detection
